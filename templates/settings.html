Facebook authentication

Create an app at developers.facebook.com, then generate a Page access token in the Graph API Explorer with the permissions pages_read_engagement, read_insights, and pages_show_list. Use the Access Token Debugger to exchange it for a long-lived token.

Find it under your Page's About → Page transparency, or in the Graph API Explorer via me/accounts.

No token saved yet.

Security notes

  • Credentials are stored in the server-side .env file (file mode 600), which is git-ignored and never committed.
  • The saved token is never sent back to the browser — only a masked preview is shown. Leaving the token field empty keeps the existing token.
  • Prefer a long-lived Page token; short-lived tokens from the Explorer expire in about an hour.
  • If you deploy this dashboard publicly, put it behind authentication — this settings page itself is not password-protected.
